# 🥖 SHOP Bakery - Сучасна пекарня

Сучасний односторінковий веб-сайт для мережі пекарень "SHOP Bakery" з адаптивним
дизайном та інтерактивними елементами.

## 🛠 Технології

- HTML5, CSS3, JavaScript (Vanilla)
- Swiper.js — слайдер форматів
- Google Fonts (Poppins)
- Google Maps API

## ✨ Функціональність

- Адаптивний дизайн (мобільні, планшети, десктопи)
- Мобільне меню
- Модальне вікно для замовлення дзвінка
- Слайдер форматів пекарень
- Контактна форма
- Інтеграція Google Maps
- Плавна прокрутка - навігація по сайту

Проєкт задеплоєний на **GitHub Pages**.
